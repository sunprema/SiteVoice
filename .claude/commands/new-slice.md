Create a new development slice.

Arguments: $SLICE_NUMBER $SLICE_NAME

Steps:

1. Create directory `slices/$SLICE_NUMBER-$SLICE_NAME/`
2. Create SLICE.md with acceptance criteria template
3. Create TASKS.md with task checklist template
4. Create CONTEXT.md listing what to read and which slices it depends on
5. Update the slices index in CLAUDE.md
